# Trust model

The main polynomial theorem and every proof in its dependency chain are checked by Lean's kernel. The completed project uses no proof hole, project axiom, native-decision tactic or unsafe proof bypass. The independently executed Audit.lean reports 978 declarations: 972 use only propext, Classical.choice and Quot.sound; 6 are axiom-independent. The main, finite, large-degree, sharpness, solution and Toeplitz conclusions each have exactly the three permitted foundational axioms.

Python programs, HTTP transfers, certificate hashes, JSON parsers and source generators are untrusted. They propose data or report reproduction checks; none is an assumption in a mathematical theorem. Checker.lean proves all 22 primitive dispatch branches for parameters constructed from an actual polynomial counterexample. Every concrete leaf acceptance, all 72 block exclusions and the final finite theorem have compiled.

Ordinary decide +kernel reduces exact Nat/Int/Rat computations inside Lean's kernel. Generated leaf theorems certify explicit rational boxes and evidence. Separate equality proofs identify those boxes with their paths in the original binary trees. Closed-child coverage and the proved degree partition cover the full parameter box and every degree from 4 through 100000. Changing or omitting generated data cannot establish the required coverage and acceptance theorem merely by changing a Python report.

The 760 selected project declarations, solution and all 217 public reused proofs are audited directly. The 33,671 generated leaf acceptances and their path equalities are audited transitively through the 72 block exclusion theorems. verification/axioms-final.log is the complete independent Lean output; tools/verify_axiom_log.py checks that every requested declaration is reported exactly once and that only permitted axioms occur. This Python accounting is not itself a logical kernel.

tools/ReuseUsage.lean is a read-only metadata inspection. It reports exact Lean types and which reused declarations are reached from the completed project's proofs. Its output is not imported by any mathematical theorem and does not replace #print axioms. The final report finds 65 reached reused declarations and 152 unused supporting exports.

The lexical source audit supplements Lean's closure audit by scanning all project/vendor/tool proof sources, with comments and strings removed. A separate final scan covers the eight scratch Lean files. Neither lexical scans nor hashes are mathematical proofs.

The final default build includes the actual polynomial main theorem, Solution, ManuscriptCheck and Audit. The clean verification removed final-entry artifacts and rebuilt final modules while retaining newly verified numerical modules and the pinned dependency cache. The report states this scope explicitly; it makes no claim of a completely empty-cache rebuild of Mathlib.

The pinned compiler and Mathlib, their ordinary kernel-checking behavior and the three foundational axioms form the logical trust boundary. Source correspondence and statement review separately check that the formal conclusions represent the user's manuscript, including multiplicities, strict counterexamples, endpoints and normalization.
